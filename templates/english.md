# 英语 log 模板（参考）

文件名格式：`YYYY-MM-DD-english-log-NN-<slug>.md`

例：`2026-06-15-english-log-01-shadowing.md`

固定结构（每篇都用同一套，方便回看 + 系列页聚合）：

1. **本期一句话** — 这段时间学英语最值得记的一件事
2. **这段时间做了什么** — 方法 / 工具 / 材料 + 大概投入时间
3. **遇到的问题 / 卡点** — 诚实写，卡点本身就是最好的素材
4. **产生的想法** — 学语言路上冒出来的念头，哪怕跑题
5. **下一步** — 给下一篇留钩子

核心原则（和正文里立的一致）：

- 以**输出和真实交流**为主，不只刷阅读和考试题
- **允许中断**，但中断后必须回来，不自我谴责
- **长期主义**，用年来计，不用周来计

如果一个月以上没更新，写一篇"为什么停了"也算合格——比悄悄消失体面。
